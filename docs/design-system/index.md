# Skill Lens 视觉规范 v0.2

## 产品工作

Skill Lens 是 Codex 里的只读检查器，不是数据看板。用户需要在一个稳定位置完成三件事：先确认当前 Session 实际检测到了哪些 Skill，再按需进入全部目录，最后阅读完整说明。

唯一打开方式是点击 Codex 侧边栏中的 Skill Lens 入口。不得要求用户通过聊天消息、`@mention` 或提示词来“查询 Skill”。

## 品牌原则

**安静、准确、紧凑。** 品牌不靠大 Logo、装饰背景或卡片堆叠表达，而靠一致的信息密度和可信的状态措辞表达。

- 视觉签名只有 14px 的镜片符号；不再使用大图标和英文副标题。
- 主色 `#3859D6` 只用于焦点、选中态与可操作文本。
- 读取证据使用 `#23865F`，且必须同时出现“读取”文案，不能只靠颜色。
- 页面只使用中性色背景、1px 分隔线和 7px 控件圆角；不使用渐变、网格纹理、浮层阴影或大卡片。

## 字体系统

只保留两个字体角色：

- UI 与阅读正文：系统 Sans（Inter / SF / Segoe UI）。
- 仅原文与行内代码：系统 Mono（SF Mono / Menlo）。

字号限制为四档：11px 状态、12px 辅助信息、14px 主体、18–22px 章节与页面标题。相同语义必须使用同一字号与字重。

## 布局与密度

- 宽屏：292px Skill 目录 + 流式阅读区。
- 顶栏固定 52px；其下用紧凑双标签区分“当前 Session”和“全部 Skill”。当前 Session 永远是默认标签，不能用复选框替代这一层产品主次。
- “当前 Session”默认页只展示检测到读取的 Skill，不显示搜索或来源筛选。
- 当前 Session 摘要行使用一个 6px 状态点表达自动更新状态，并提供紧凑的“跟随当前 / 固定此 Session”文字控件；不新增卡片或独立设置页。
- 搜索、来源下拉和结果数只属于“全部 Skill”目录；搜索是面板内的本地定位，不向 Codex 发消息。
- 列表单项默认约 54px；说明只展示一行，完整说明在右侧阅读区展开。
- 详情不再套卡片。标题、说明、来源和路径组成一个紧凑头部，正文直接进入阅读区。
- 默认展示渲染后的“阅读”模式，同时保留“原文”切换，确保全文可核对、可复制。

## 状态语言

- 当前 Session 有本地 Hook 证据：`刚刚读取` / `N 分钟前读取`。
- 只在其他 Session 有证据：仅在“全部 Skill”中显示 `历史记录 · N 天前读取`。
- 当前 Session 无证据：显示诚实空状态，并提供“查看全部 Skill”，不暗示未使用或已经加载。
- 自动更新正常：`自动更新`；暂时失败：`自动更新暂时中断`，同时保留最后一次可用内容。
- 永久边界说明：读取证据不等于官方 `SkillActivated` 事件。

## 可访问性

所有筛选都有文本标签；选中态不只靠颜色；正文保持高对比；控件可键盘聚焦；窄屏改为上下结构，不隐藏完整正文。

## 可运行预览

执行 `npm run build && npm run preview`，打开 `http://127.0.0.1:4173/preview.html`。本地预览服务读取真实 Skill，不再用短示例冒充真实内容；静态打开时会明确标注为演示数据。
