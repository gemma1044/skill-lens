# Skill Lens 视觉规范 v0.1

## 产品工作

让用户像查看调试仪器一样，一眼确认 Skill 的来源、读取信号和完整说明。界面不是运营看板，而是安静、可信、可长期停留的工作台。

## 视觉签名

唯一强调元素是“扫描镜片”：青色同心环表示正在索引，橙色光点只表示检测到实际文件读取。其余界面保持冷静，避免每个状态都抢注意力。

## Foundations

- 颜色：工作台 `#E8EEF4`、纸面 `#F8FAFC`、墨色 `#142132`、镜片青 `#1F9D96`、活动橙 `#F27649`、代码底 `#101B2A`。
- 字体：标题使用 Avenir Next；正文使用 Avenir / Segoe UI；路径和原文使用 SF Mono / Consolas。
- 形状：工作区 20px 圆角，控件 11–13px，状态使用完整圆形；不使用装饰性胶囊堆叠。
- 布局：宽屏为目录轨道 + 原文观察窗；窄屏上下堆叠，目录高度不超过视口 52%。
- 动效：只有扫描环持续运动；列表位移 2px；遵守 `prefers-reduced-motion`。
- 可访问性：键盘可聚焦、状态不只靠颜色、正文保持高对比、触控目标至少 42px。

## 核心组件

- `SkillRow`：名称、两行触发说明、来源、读取状态点。
- `SourceFilter`：全部、检测到读取、个人、项目、插件、配置。
- `SkillViewer`：标题、触发说明、来源元数据和原始 `SKILL.md`。
- `ActivityBadge`：只在有 Hook 证据时出现，文案必须包含“检测到读取”。
- `ScopeNotice`：永久解释推断边界，不隐藏在 hover 中。

## Do / Don't

- Do：把原文作为第一等内容，路径可追溯，未知状态明确写未知。
- Don't：把推断写成“已激活”；不要用彩色卡片装饰每个 Skill；不要编辑用户文件。

## 可运行预览

执行 `npm run build && npm run preview`，打开 `http://localhost:4173/preview.html`。
