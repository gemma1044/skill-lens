# 当前 Session Skill 视图 v0.1.1

## 问题

v0.1.0 的列表默认展示全量扫描目录，“只看读取过”也会混入其他 Session 的历史记录。这会让用户误以为 Codex 在当前会话加载了机器上的全部 Skill。

## 本轮修改

- 默认标签改为“当前 Session”，只纳入 `sessionId` 与当前会话匹配的读取记录。
- “全部 Skill”保留为次级目录，用于搜索和检查本机 Skill。
- 全量目录中的历史证据明确标为“历史记录”，与当前 Session 证据分开。
- 无当前读取证据时展示空状态，不用全量目录填充主视图。
- 排除插件自身的全文读取，避免用户检查某个 Skill 后把它误记为 Codex 当前使用。

## 保持不变

- 仍然只读，不修改任何 Skill。
- 仍扫描个人、项目和插件目录。
- 仍可切换阅读 / 原文并复制完整 `SKILL.md`。
- Hook 证据仍是“检测到读取”，不升级为官方 `SkillActivated` 结论。

## 验收口径

使用两个不同的 Session 写入两条读取记录：当前 Session 标签只能出现匹配记录；全部 Skill 标签同时包含两项，并把非当前记录标为历史。
